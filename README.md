# RememberKey

Личное Android-приложение для ASUS ROG Phone 9 Pro. Помогает выучить три ключа (пароли из символов) и не забыть их никогда. Главное хранилище — голова. Телефон напоминает о проверках, сверяет ввод и хранит зашифрованную копию на случай, если ключ забылся.

- `app/` — приложение (Kotlin, Jetpack Compose): светлая и тёмная тема по настройке телефона, крупные заголовки, карточки, синий акцент.
- `core/` — логика без Android: правила ключей, расписание, паузы PIN, формат файла хранилища, криптография. Здесь же юнит-тесты.
- `design/` — HTML-прототип (`prototype.html`) и 15 вариантов оформления (`styles.html`).
- `diag/` — отдельное приложение «RK диагностика» для проверки возможностей телефона.

## Как работает

- **Ключ** — только символы: буквы, цифры и знаки без пробелов. Везде показывается блоками по 4.
- **Добавление.** Ключ вводится дважды или один раз вставляется из буфера обмена — после вставки буфер сразу очищается. Затем PIN приложения и отпечаток.
- **Уроки по блокам.** Каждый блок 3 раза с подсказкой перед глазами, потом 3 раза по памяти, затем следующий блок. В конце весь ключ 3 раза подряд. Прерванный урок продолжается с того же блока.
- **Карточка ключа** показывает, какие блоки помнятся хорошо и какие плохо: по последним вводам по памяти в уроках, тренировках блоков и при подсмотре. Любой блок можно потренировать отдельно (PIN и отпечаток, расписание не сдвигается).
- **Проверки** идут через 1, 3, 7, 16, 35 и 60 дней, дальше каждые 60. Напоминание приходит в 9:00.
  - Верно с первой попытки — интервал растёт.
  - Верно не с первой попытки — тот же интервал ещё раз.
- **Тренировка** — проверка раньше срока. Ключ нужно ввести верно 3 раза, расписание не меняется.
- **Подсмотр:** PIN приложения, затем отпечаток. Подсказки идут по уровням: «где ошибка», «одно слово или блок», «целиком, пока держите кнопку».
  - Каждый подсмотр записывается в журнал. Журнал нельзя очистить.
  - Если что-то открыли, ключ сразу нужно ввести по памяти. Следующая проверка — завтра, интервалы начинаются заново.

## Защита

| Что | Как |
|---|---|
| Проверка по памяти | `HMAC(K_ver, Argon2id(ключ))`. `K_ver` хранится в защищённом чипе (TEE) и не покидает его. PIN и отпечаток для проверки не нужны |
| Копия ключа | `AES-GCM(ключ_PIN, AES-GCM_TEE(K_bio, ключ))`. `K_bio` у каждого ключа свой. Каждая операция с ним требует отпечатка класса 3, а новый отпечаток в настройках Android его уничтожает |
| PIN приложения | 8 цифр, `Argon2id` (128 МиБ) + `HMAC` в чипе. После 3-й ошибки — пауза 30 с, затем 1, 5 и 15 минут. Ничего не стирается |
| Экран | Скриншоты, запись экрана и превью в списке приложений запрещены. Окна других приложений поверх скрыты. Службы спецвозможностей, кроме настоящих инструментов доступности, экран не видят |
| Ввод | Своя клавиатура: системная клавиатура и буфер обмена ключа не видят |
| Данные | Нет разрешения на интернет. Нет резервного копирования Android. Файл лежит в `noBackupFilesDir` и содержит только соли, хеши и шифротекст |

Если система уничтожила ключ отпечатка, приложение замечает это при запуске и помечает копию как утерянную.
- Ничего не удаляется. Если это был временный сбой сканера, при следующей проверке копия вернётся.
- Хеш остаётся, поэтому копию можно восстановить: ввести ключ по памяти, затем PIN и отпечаток.

Когда приложение уходит в фон:
- открытая копия закрывается;
- набранный ввод, ключ на заучивании и незаконченное добавление стираются из памяти.

Чтобы продолжить заучивание, снова нужны PIN и отпечаток.

### Ограничения

- Удаление приложения, сброс телефона или его потеря уничтожают и хеши, и копии. Ключи должны жить в голове.
- Пока ключ показан на экране или идёт заучивание, он лежит в памяти процесса обычной строкой Java. Без root другие приложения эту память прочитать не могут.

## Сборка

Нужны JDK 17+ и Android SDK. Путь к SDK указан в `local.properties`, файл не хранится в git.

```bash
./gradlew :core:test            # юнит-тесты логики и криптографии
./gradlew :app:assembleRelease  # APK для телефона
```

Готовый APK лежит в `app/build/outputs/apk/release/app-release.apk`. Если папки `signing/` нет, APK собирается неподписанным: отладочным ключом приложение для телефона не подписывается никогда.

Отладочная сборка (`assembleDebug`) ставится рядом с основной под именем `local.rememberkey.debug`. Она разрешает скриншоты, чтобы проверять экраны на эмуляторе. На телефон её не ставить.

### Ключ подписи

Release-сборка подписывается ключом из `signing/release.jks`. Пароли лежат в `signing/keystore.properties`. Папки `signing/` нет в git.

**Сохраните копию папки `signing/` в надёжном месте, лучше офлайн.** Новую версию можно поставить поверх старой только с тем же ключом. Иначе приложение придётся удалить, а удаление уничтожает все ключи в чипе, хеши и копии. Тот, у кого есть этот ключ и доступ к разблокированному телефону, может поставить поддельное обновление. Поэтому храните его как секрет.
