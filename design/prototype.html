Сценарий

Правила — предложение

  • Проверка идёт по хешу: PIN и отпечаток не нужны, ключ не расшифровывается.
  • Верно с первой попытки — следующий интервал: 1 → 3 → 7 → 16 → 35 → 60 дней, дальше всегда каждые 60.
  • Верно не с первой попытки — тот же интервал ещё раз.
  • Раньше срока — тренировка: ключ нужно ввести верно 3 раза, ошибка счёт не сбрасывает. Расписание не меняется.
  • Подсмотр: PIN приложения, потом отпечаток. Три уровня — где ошибка → одна часть → целиком, пока держите кнопку. Экран закрывается сам через 60 секунд.
  • После подсмотра — сразу ввод по памяти, проверка завтра, интервалы заново. Открыть копию и ничего не посмотреть — не считается.
  • Неверный PIN: после третьей ошибки пауза 30 с, дальше 1, 5, 15 минут. Ничего не стирается.
  • Новый ключ: ввод дважды → отпечаток (шифруем копию) → заучивание, 3 раза подряд по памяти.
  • Журнал нельзя очистить.

В макете не видно

  • Скриншоты, запись экрана и превью в списке приложений запрещены.
  • Ключ не попадает в буфер обмена и в уведомления.
  • У приложения нет доступа в интернет; данные не уходят в резервную копию Android.
  • Расшифрованный ключ стирается из памяти сразу после показа.
  • Окно отпечатка в приложении системное (BiometricPrompt), здесь нарисовано похожее.

Форматы ключей

Два формата: фраза (A) и символы (B). Фраза везде показывается строкой, символы — блоками по 4. В «Защите» — результаты диагностики вашего телефона от 21 ноября.
