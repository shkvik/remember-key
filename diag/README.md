# RK диагностика

Отдельное маленькое приложение: проверяет, какие механизмы защиты есть в телефоне, и сохраняет отчёт в JSON. По отчёту выбираем, как RememberKey будет хранить ключи.

- Создаёт только временные тестовые ключи и сразу их удаляет. Паролей не спрашивает.
- Разрешения на интернет нет: отчёт уходит с телефона только через «Поделиться».

## Что проверяет

| Раздел JSON | Что внутри |
|---|---|
| `device` | модель, Android, уровень патча безопасности |
| `features` | заявленные системой функции: StrongBox, версия KeyMint, сканеры |
| `lock_biometric` | есть ли блокировка экрана, класс биометрии |
| `environment` | отладка по USB, службы специальных возможностей, шифрование памяти, системные свойства загрузки |
| `keystore_tee`, `keystore_strongbox` | AES-256-GCM, HMAC-SHA256 и аттестация EC P-256: создаётся ли ключ, фактический уровень защиты, скорость, работает ли условие «только при разблокированном телефоне». В аттестации — состояние загрузчика и Verified Boot, подписанное чипом, и цепочка сертификатов |
| `argon2id` | сколько миллисекунд занимает Argon2id при 19, 64 и 128 МиБ |
| `biometric_test` | после кнопки «Тест с отпечатком»: ключ с отпечатком на каждую операцию — без пальца отказ, с пальцем работает, одно касание открывает ровно одну операцию |

## Сборка

```bash
cd diag
./gradlew :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Подписан отладочным ключом — для диагностики этого достаточно, секретов приложение не хранит.

На эмуляторе StrongBox нет, а ключи программные (`SOFTWARE`), поэтому настоящие ответы даёт только телефон.
